# CSC303-Lab-Assessment
CSC 303 Lab Assessment

Database Design, SQL Implementation and Normalization

This repository contains the Python source files used for my CSC 303 lab assessment at Miva Open University.

Question 1: ER Model and Relational Schema Design
The database design covers students, courses, instructors and enrolments.

Question 2: SQL Database Implementation
File: `csc303_database.py`

This program creates the university database, inserts sample records and runs SQL queries to retrieve student enrolments, instructor details and course enrolment counts.

Question 3: Database Normalization
File: `csc303_normalization.py`

This program creates the Employee, Course and Employee_Training tables, inserts the supplied training records and retrieves the normalized information using SQL JOIN.
